## Selected builds

### [ScamBait AI](https://github.com/Aryan1092raj/HoneyPot) · selected for India AI Impact Buildathon 2026

An automated scam honeypot built around a five-layer pipeline: detection, red-flag classification, deterministic state transitions, four AI personas, and intelligence extraction.

- Keeps termination logic in backend code while the LLM handles in-character Hinglish / English replies.
- Extracts UPI IDs, phone numbers, phishing URLs, and bank accounts with regex-backed evidence collection.
- Prototype deployed on Render.

<code>Python</code> <code>FastAPI</code> <code>Groq LLaMA-3.3-70B</code> <code>Regex NLP</code>

### [IIT Mandi JoSAA Chatbot](https://github.com/RemanDey/chatbot-josaa-iitmandi) · co-developed with 1 teammate

A counselling assistant grounded in official JoSAA material and delivered over WhatsApp and Telegram.

- Built the RAG pipeline used for AI-generated counselling answers.
- Maintained the Hugging Face inference backend behind Flask, Twilio, and Telegram webhooks.
- Added provider failover across Gemini, Groq, Cerebras, and Mistral.

<code>Python</code> <code>Flask</code> <code>RAG</code> <code>Twilio</code> <code>Telegram</code> <code>Hugging Face</code>

### [FinAgent](https://github.com/Aryan1092raj/FinAgent) · stateful browser agent

A financial research agent that keeps task and conversation state across interactions, then turns one natural-language request into a multi-step workflow.

<code>FastAPI</code> <code>PostgreSQL</code> <code>React</code> <code>Browser Automation</code>

### [ResQLink](https://github.com/Aryan1092raj/GoogleSolutions) · Google GDG Solution Challenge 2026

An emergency response system with a Flutter guest SOS app, a web dashboard, live Firebase state sync, WebSockets, JWT, Google OAuth, and Gemini / Vertex AI incident analysis.

<code>Flutter</code> <code>Node.js</code> <code>TypeScript</code> <code>Firebase</code> <code>WebSocket</code>

### [GeoLedger](https://github.com/Aryan1092raj/Stellar) · blockchain charity platform

A Stellar testnet charity platform with Soroban contracts for donations, NGO verification, impact escrow, token management, NFT minting, and evidence.

<code>Rust</code> <code>Soroban</code> <code>Stellar</code> <code>Next.js</code> <code>Prisma</code> <code>IPFS</code>

### [Brain](https://github.com/Aryan1092raj/Daemon) · local-first codebase intelligence

A codebase daemon that maps files, symbols, commits, modules, imports, calls, and touches into a Kuzu knowledge graph, then uses decay scoring, hot-zone detection, BFS ripple analysis, and natural-language-to-Cypher queries.

<code>Node.js</code> <code>Kuzu</code> <code>SQLite</code> <code>tree-sitter</code> <code>MCP</code>
